Website Concierge Overview

Brixa Assistant lets guests start a conversation with your hotel from your website. This article explains where staff set it up and what to prepare before adding it to a live page.

What guests see

When it is enabled and installed, Brixa Assistant appears on your hotel website as a chat option. Guests can use it to ask about their stay while they browse your site. Their conversations appear in the same Brixa inbox your team already uses for guest communication. See Viewing Conversations for help working in the inbox.

Where staff manage it

Open Sales and then Brixa Concierge in Brixa. Select the hotel you want to configure before making changes. This page is where you enable the website chat, choose the websites where it may appear, set its appearance, and copy the installation snippet.

Prepare these details first

  • Your website address. You need the full origin for every site or subdomain where the chat will appear, such as https://www.examplehotel.com. If guests use both your main site and a booking subdomain, prepare both addresses.
  • Access to your website. Someone on your team or your web provider needs to be able to add the Brixa Assistant snippet to the site.
  • Your guest-facing wording. Decide whether to use the default welcome text or add a hotel-specific title, greeting, placeholder, and suggested questions.

Set it up in order

  1. Configure and save Brixa Concierge for the selected hotel.
  2. Copy the current installation snippet from the Brixa Concierge page.
  3. Add that snippet to the website.
  4. Open the website as a guest and send a test message.
