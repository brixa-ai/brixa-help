Configure the Website Concierge

Use the Brixa Concierge page to enable Brixa Assistant for a hotel, list the websites where it can appear, and tailor its appearance and welcome screen for guests.

Open the correct hotel

In Brixa, select the hotel you want to configure. Then open Sales and choose Brixa Concierge. Each hotel has its own settings, so always confirm the selected hotel before you save.

Enable the website chat and add website origins

  1. Turn on Enable widget.
  2. Under Allowed website origins, enter one full website origin per line. For example: https://www.examplehotel.com and https://booking.examplehotel.com.
  3. Use the address only: include https://, but do not add a page path, query, or trailing slash. For local testing, http://localhost is accepted.
  4. Select Save.

The first save creates the configuration and makes a widget key available. You need that current key in the website snippet.

Set the appearance

In the Appearance section, choose the primary color and whether the launcher sits at the bottom right or bottom left of the page. Match these settings to your hotel website so guests recognize the chat as part of your experience.

Set the guest experience

In Guest experience, you can set the default language, header title, subtitle, message-box placeholder, greeting, and suggested questions. Keep the wording short and helpful. Suggested questions are shown one per line and give guests an easy way to start a conversation.

Save after changing these fields, then open your website in a new browser tab to review how the updated chat looks to guests.

Copy or regenerate the widget key

Once the widget is enabled, has at least one allowed website origin, and has been saved, Brixa Concierge shows the installation snippet. Use Copy snippet to copy the current version for your website.

Use Regenerate key only when you deliberately want to replace the current key. Regenerating it stops any website still using the old snippet from loading Brixa Assistant. Copy the new snippet and update every website where you installed it before relying on the chat again.

Next step

After saving, follow Install the Website Concierge on Your Website to add the snippet and test it as a guest.
